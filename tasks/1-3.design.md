# Design 1-3

## Requirements

**滚动行为优化**：
修改`focusBubble()`方法中的`scrollIntoView`参数，移除`inline: 'center'`以避免水平居中导致的"右移感"。此修改基于1-2的成功验证，进一步优化用户交互体验。

**具体要求**：
- 保持垂直居中滚动行为
- 消除水平方向的滚动跳动
- 确保iOS Safari兼容性
- 保持聚焦动画和其他交互效果不变

## Solution

**滚动行为修改**：

1. **定位修改点**：
   - 文件：`static/js/bubble-words.js` 
   - 方法：`focusBubble()`
   - 位置：约第361-365行的`scrollIntoView`调用

2. **修改实施**：
   ```javascript
   // 修改前：
   targetBubble.scrollIntoView({ 
       behavior: 'smooth', 
       block: 'center', 
       inline: 'center' 
   });

   // 修改后：
   targetBubble.scrollIntoView({ 
       behavior: 'smooth', 
       block: 'center'
       // 移除 inline: 'center' 避免水平居中导致的视觉跳动
       // iOS Safari 对 inline 参数支持不一致，完全移除更安全
   });
   ```

3. **代码注释说明**：
   ```javascript
   // 将目标气泡垂直居中显示，保持水平位置不变
   // 移除 inline 参数以避免水平滚动引起的"右移感"
   targetBubble.scrollIntoView({ 
       behavior: 'smooth', 
       block: 'center'
   });
   ```

## Tests

**滚动行为验证测试**：

1. **基础滚动测试**：
   - 点击不同位置的气泡
   - 验证目标气泡能正确垂直居中
   - 确认整体布局保持左对齐，无水平位移

2. **连续交互测试**：
   - 连续点击不同行的气泡
   - 验证无水平"抖动/漂移"现象
   - 测试右边界气泡点击，确认无水平回弹

3. **设备兼容性测试**：
   - Chrome桌面版测试
   - Safari桌面版测试
   - 移动端Safari测试（如果可用）
   - 验证滚动行为在各平台一致

4. **聚焦效果测试**：
   - 确认放大、虚化动画正常
   - 验证聚焦状态下的左对齐保持
   - 测试3秒后自动恢复功能

5. **回归验证**：
   - 对比修改前的行为差异
   - 确认用户体验改善（无"右移感"）
   - 验证所有交互功能完整性
