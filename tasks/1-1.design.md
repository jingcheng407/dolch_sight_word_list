# Design 1-1

## Requirements

**准备工作和环境验证**：
1. 创建修改前的视觉基准截图，用于后续效果对比和回归验证
2. 备份将要修改的关键文件，确保快速回滚能力
3. 验证测试环境能正常访问和使用气泡探索功能
4. 记录当前的问题表现，为验证修复效果做准备

**具体要求**：
- 在桌面和移动端分别截图气泡探索的初始状态
- 截图点击气泡后的聚焦状态，记录左边界位置
- 备份`bubble-words.css`和`bubble-words.js`文件
- 验证当前版本号v=6的CSS文件正常加载

## Solution

**准备步骤**：

1. **环境验证**：
   - 启动开发服务器：`uv run python main.py`
   - 访问`http://localhost:8000/dolch_games_demo.html`
   - 点击"气泡探索"按钮，确认功能可正常使用

2. **创建视觉基准**：
   - 截图1：气泡探索初始状态（显示当前的右侧分布）
   - 截图2：点击首行第一个气泡后的聚焦状态
   - 截图3：不同屏幕尺寸下的显示效果
   - 保存截图到`tasks/`目录作为基准

3. **文件备份**：
   ```bash
   cp static/css/bubble-words.css static/css/bubble-words.css.backup
   cp static/js/bubble-words.js static/js/bubble-words.js.backup
   ```

4. **问题记录**：
   - 记录当前左边界位置（像素值）
   - 记录聚焦态左边界跳动现象
   - 记录用户感觉的"右移感"具体表现

## Tests

1. **环境测试**：
   - 开发服务器正常启动
   - 气泡探索功能可正常访问和点击
   - CSS v=6版本正确加载

2. **基准记录**：
   - 成功创建3张不同状态的截图
   - 备份文件完整且可读
   - 问题现象清晰记录和量化

3. **快速验证**：
   - 能够通过备份文件快速恢复原状态
   - 截图质量足够用于像素级对比
   - 测试环境稳定可重复
