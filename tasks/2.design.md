# Design 2 - 右侧单词详情面板

## Requirements
- 移除弹窗式单词详情显示
- 创建右侧固定详情面板，提高学习效率
- 点击单词卡片时在右侧面板显示详情
- 保持多邻国风格设计一致性
- 支持桌面和移动端响应式布局

## Solution
### 布局设计
- 桌面端：左右分栏布局（左侧70%单词网格，右侧30%详情面板）
- 移动端：保持现有布局，将详情面板放在底部或使用折叠设计
- 详情面板包含：单词、发音、词性、例句、功能按钮

### 技术实现
1. 修改LearnTab组件布局为flex横向布局
2. 创建WordDetailPanel组件替代WordModal
3. 调整单词网格容器宽度和响应式规则
4. 保持现有的状态管理逻辑

### 设计规范
- 使用多邻国渐变色彩
- 面板有圆角和阴影效果
- 平滑的切换动画
- 默认状态显示学习提示

## Tests
- 桌面端布局正确显示
- 移动端响应式适配
- 单词点击切换功能正常
- 所有原有功能保持完整
- 视觉效果符合多邻国风格
