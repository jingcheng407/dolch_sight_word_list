# Design 2

## Requirements

### 背景与目标
解决当前儿童英语学习应用中存在的文字渲染问题，提升在各种设备和浏览器上的字体显示效果和性能，确保儿童用户在不同设备上都能获得清晰、一致的阅读体验。

### 核心问题分析
基于用户反馈的截图和代码审查，当前应用存在以下文字渲染和可读性问题：

1. **字体加载问题**：
   - Google Fonts 外部字体加载可能导致延迟或失败
   - 网络不稳定时字体回退效果不佳
   - 字体加载完成前出现布局跳动（FOUT/FOIT）

2. **文字颜色对比度不足（经测试确认）**：
   - **严重问题**：主要色彩 `#ff6b6b` 对比度仅 2.78（需要≥4.5），强调色 `#ffe66d` 对比度仅 1.25
   - **可用但边缘**：浅色文字 `#636e72` 对比度 5.24，勉强达到AA标准但在某些设备上仍可能模糊
   - **良好**：深色文字 `#2d3436` 对比度 12.68，符合AAA标准
   - 梯度背景与文字颜色搭配导致局部区域可读性极差
   - 类别标签、按钮文字、重要提示使用不达标颜色，严重影响用户体验
   - 缺少高对比度模式，无法满足视力辅助需求

3. **跨设备渲染不一致**：
   - 不同操作系统字体渲染引擎差异
   - 高分辨率屏幕与普通屏幕显示效果不一致
   - 各浏览器字体抗锯齿效果不统一
   - 暗色模式和明亮环境下文字可见性问题

4. **响应式字体大小问题**：
   - clamp() 函数在某些浏览器兼容性问题
   - 字体缩放时出现模糊或锯齿
   - iPad等设备横竖屏切换时字体显示异常

5. **性能影响**：
   - 多个字体文件同时加载影响首屏渲染速度
   - 字体抗锯齿计算消耗GPU资源
   - 复杂的CSS颜色计算影响渲染性能

### 功能需求

1. **字体回退策略优化**：
   - 建立完善的字体堆栈，确保在外部字体加载失败时有合适回退
   - 为中文和英文分别优化字体选择
   - 儿童友好的可读性保障

2. **颜色对比度优化系统**：
   - 重新设计颜色变量，确保所有文字达到 WCAG AA 级别对比度（4.5:1）
   - 针对不同背景（纯色、梯度、图片）提供自适应文字颜色
   - 实现智能文字颜色检测，根据背景亮度自动调整前景色
   - 提供高对比度模式切换功能
   - 支持用户自定义对比度级别

3. **动态字体加载机制**：
   - 实现字体预加载和渐进式加载
   - 检测字体加载状态，提供加载反馈
   - 根据网络状况智能选择字体策略

4. **渲染优化**：
   - 针对不同设备类型优化字体渲染参数
   - 解决高DPI屏幕显示问题
   - 统一跨浏览器字体显示效果
   - 优化文字阴影和边框效果，提升可读性

5. **响应式字体系统**：
   - 优化clamp()函数的浏览器兼容性
   - 提供fallback机制确保字体大小适配
   - 支持实时屏幕尺寸和方向变化

6. **环境适应性**：
   - 检测设备类型和屏幕特性
   - 提供手动室内/室外模式切换（环境光检测在Safari不可用）
   - 支持系统深色/浅色主题自动切换
   - 为儿童用户优化视觉参数

### 性能和兼容性要求

1. **性能指标（体验导向）**：
   - FOIT = 0（通过`swap`/`optional`策略实现）
   - 首屏"文本可读时间" ≤ 2s（弱网用回退字体达成）
   - 字体切换导致的CLS ≤ 0.02（配合metrics override）
   - 监控项：字体策略、FOUT发生次数、回退占比

2. **兼容性范围**：
   - iOS Safari 14+
   - iPadOS Safari 14+
   - Chrome 90+
   - 支持2G/3G网络环境

3. **可访问性**：
   - 符合WCAG 2.1 AA级别对比度要求
   - 支持系统字体大小缩放
   - 保持儿童用户的视觉友好性

### 技术约束

1. **现有架构保持**：
   - 不改变当前CSS框架结构
   - 保持现有的儿童友好设计风格
   - 向后兼容现有功能

2. **资源限制**：
   - 总字体资源大小控制在 200KB 以内
   - 不引入重量级字体库
   - 优先使用系统字体和web safe字体

3. **实现方式**：
   - 纯CSS+JavaScript解决方案
   - 渐进式增强策略
   - 优雅降级保障

### 验收标准（更新为可量化指标）

1. **可读性合规**：
   - 所有文字元素达到WCAG AA对比度标准（≥4.5:1）
   - 正文字体大小≥17px，标题≥22px
   - 复杂背景文字统一使用遮罩或面板承载

2. **字体加载体验**：
   - 零FOIT（无不可见文本闪烁）
   - 弱网环境允许适度FOUT（≤300ms切换时间）
   - 字体切换导致的CLS ≤ 0.02

3. **兼容性保障**：
   - 目标浏览器（Safari 14+, Chrome 90+）测试通过
   - 字体加载失败时自动回退到系统字体
   - 高对比度模式和无障碍功能正常

4. **性能标准**：
   - 首屏"文本可读时间" ≤ 2s
   - typography.css文件大小 ≤ 10KB
   - 无额外JavaScript阻塞（字体检测脚本使用defer加载）

### 风险评估

1. **技术风险（低）**：
   - 某些老版本浏览器可能不支持font metrics override（有graceful fallback）
   - 字体回退可能影响视觉一致性（但通过font-display策略可控）

2. **性能风险（极低）**：
   - CSS变量重定义无性能影响
   - font-display策略减少而非增加阻塞

3. **维护风险（可控）**：
   - 主要为CSS变量调整，维护成本低
   - 测试自动化减少手工测试工作量

### 开放问题（需产品/设计确认）

1. **字体来源偏好**：是否允许使用Google CDN？如受限则改自托管
2. **品牌色向"文本安全色"的允许偏移幅度**（明度/饱和度/色相）
3. **是否统一在图片/渐变背景上加遮罩**（更易落地但有视觉取舍）
4. **是否接受使用font metrics override**（现代特性）以换取更低CLS？
5. **视觉回归测试是否落地到本仓库**（引入Node工具链），或先走手测流程？

---

本需求文档重点关注提升儿童用户的阅读体验，通过技术手段解决字体渲染的一致性和性能问题，确保应用在各种使用环境下都能提供优质的视觉体验。

## Solution

### 1. 当前代码架构分析

#### 1.1 颜色使用模式
通过代码分析发现当前颜色管理方式：
- **CSS变量系统**：在`:root`中定义了完整的颜色变量
- **JavaScript创建DOM**：word卡片通过`renderWordsGrid()`动态创建，使用`.word-text`和`.word-category`类
- **三套样式文件**：style.css（基础）+ responsive.css（响应式）+ ipad.css（iPad优化）
- **渐进式增强**：已有`@media (prefers-contrast: more)`和`@media (prefers-color-scheme: dark)`支持

#### 1.2 关键发现
- 颜色问题主要在CSS变量定义层面，不需要修改JavaScript逻辑
- 现有架构支持响应式和设备适配，具备良好的扩展性
- word-text和word-category是文字显示的核心类，修改影响范围可控

### 2. 颜色对比度优化方案

#### 2.1 核心策略：CSS变量重定义 + 智能适配

**设计原则**：
- 保持现有CSS架构不变
- 通过CSS变量重定义解决对比度问题
- 渐进式增强，确保向后兼容
- TDD驱动，每个改动都有测试覆盖

### 3. 字体加载和渲染优化方案

#### 3.1 字体加载优化策略

**当前问题**：
- Google Fonts外部依赖，加载失败风险
- 没有字体加载状态检测
- FOUT/FOIT效应影响体验

**解决方案**：

**方案A：优化Google Fonts使用（推荐，最少改动）**
```html
<!-- 预连接字体域名，降低握手开销 -->
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Fredoka:wght@400&display=swap" rel="stylesheet">
```

**方案B：自托管字体（更可控，离线稳定）**
```html
<!-- 预加载字体，避免首屏阻塞 -->
<link rel="preload" as="font" href="/static/fonts/fredoka-400.woff2" type="font/woff2" crossorigin>
```

```css
/* 自托管字体，使用metrics override降低CLS */
@font-face {
  font-family: 'Fredoka';
  src: local('Fredoka Regular'), url('/static/fonts/fredoka-400.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap; /* 弱网建议optional */
  /* 调整回退字体度量，减少切换位移 */
  ascent-override: 92%;
  descent-override: 24%;
  line-gap-override: 0%;
  size-adjust: 102%;
}

:root {
  --app-font-stack: 'Fredoka', -apple-system, BlinkMacSystemFont, 'SF Pro Text',
    'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', system-ui, sans-serif;
}

body { font-family: var(--app-font-stack); }
```

**JavaScript字体检测（增强功能）**：
```javascript
// 字体加载状态检测与管理
class FontLoader {
  constructor() {
    this.fontFamily = 'Fredoka';
    this.fallbackTimeout = 3000; // 3秒后强制使用回退字体
  }

  async checkFontAvailability() {
    // 检查浏览器支持
    if (!('fonts' in document)) {
      this.enableFallback('Browser does not support Font Loading API');
      return false;
    }

    try {
      // 设置超时保护
      const fontLoadPromise = document.fonts.load(`400 1em ${this.fontFamily}`);
      const timeoutPromise = new Promise((_, reject) => {
        setTimeout(() => reject(new Error('Font load timeout')), this.fallbackTimeout);
      });

      await Promise.race([fontLoadPromise, timeoutPromise]);
      
      document.documentElement.classList.add('fonts-loaded');
      console.info('Custom fonts loaded successfully');
      return true;
      
    } catch (error) {
      this.enableFallback(error.message);
      return false;
    }
  }

  enableFallback(reason) {
    console.warn(`Font loading fallback: ${reason}`);
    document.documentElement.classList.add('fonts-fallback');
    
    // 移除可能已设置的fonts-loaded类
    document.documentElement.classList.remove('fonts-loaded');
  }

  // 初始化字体加载
  async init() {
    // 等待DOM准备
    if (document.readyState === 'loading') {
      await new Promise(resolve => {
        document.addEventListener('DOMContentLoaded', resolve);
      });
    }

    return this.checkFontAvailability();
  }
}

// 使用示例
const fontLoader = new FontLoader();
fontLoader.init();
```
