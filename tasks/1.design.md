# Design 1

## Requirements

基于分析，当前项目是一个Dolch单词学习应用，包含学习、练习、测验和统计功能。需要将其改造为多邻国风格的UI界面：

### 当前项目状态
- Next.js + TypeScript + Tailwind CSS 项目
- 包含Dolch单词数据（Pre-primer, Primer, Grade 1-3等级别）
- 现有功能：学习、练习游戏、测验、统计
- 当前界面：传统的标签页布局，较为简单

### 多邻国风格UI要求
1. **整体设计风格**
   - 采用多邻国的绿色主题色彩（#58CC02）
   - 圆角卡片设计，友好的视觉效果
   - 明亮活泼的色彩搭配
   - 简洁现代的排版

2. **导航系统**
   - 左侧固定侧边栏（桌面版）
   - 底部标签导航（移动端）
   - 图标 + 文字的导航模式
   - 活跃状态的视觉反馈

3. **学习路径界面**
   - 类似多邻国的技能树布局
   - 不同等级的单词组织成课程单元
   - 进度指示器和解锁机制
   - 星级评分系统

4. **游戏化元素**
   - 学习进度条
   - 成就徽章系统
   - 连击计数器
   - 经验值和等级系统

5. **交互体验**
   - 平滑的动画过渡
   - 成功/失败的视觉反馈
   - 音效支持（可选）
   - 触觉反馈（移动端）

6. **响应式设计**
   - 适配桌面、平板、手机
   - 移动优先的设计理念
   - 触摸友好的交互元素

### 参考多邻国项目
项目中已包含完整的多邻国克隆代码（/github/duolingo-clone/），可作为UI设计参考：
- 使用相同的组件库（Radix UI）
- 采用类似的布局结构
- 借鉴颜色方案和动画效果
- 复用成熟的UI组件

### 技术要求
- 保持现有的Next.js + TypeScript架构
- 继续使用Tailwind CSS进行样式开发
- 集成现有的Dolch单词数据
- 保持学习、练习、测验、统计等核心功能
- 确保良好的性能和用户体验

## Solution

### 技术方案概述
基于现有项目架构，参考github/duolingo-clone项目的设计模式，分阶段重构UI界面。

### 1. 主题系统重构
- **颜色方案更新**：创建多邻国风格的颜色主题
  - 主要绿色：#58CC02（成功、主要按钮）
  - 辅助蓝色：#1CB0F6（链接、次要按钮）
  - 背景色：#F7F7F7（浅灰背景）
  - 文字色：#4B4B4B（深灰文字）
- **字体系统**：采用圆润友好的字体
- **组件库增强**：扩展现有UI组件以支持多邻国风格

### 2. 布局架构重构
- **响应式导航系统**
  - 桌面端：左侧固定侧边栏（参考duolingo-clone/components/sidebar.tsx）
  - 移动端：底部标签栏（参考duolingo-clone/components/mobile-sidebar.tsx）
  - 统一的导航项：Learn、Practice、Quiz、Stats
- **页面容器**：采用duolingo-clone的feed-wrapper模式
- **头部组件**：包含用户进度、连击计数、心形生命值

### 3. 学习路径界面（Learn Tab）
- **技能树布局**：将Dolch单词按等级组织成课程单元
  - Pre-primer → Primer → Grade 1 → Grade 2 → Grade 3
  - 每个等级显示为一个大的课程卡片
  - 卡片内显示进度环形图和解锁状态
- **单元详情**：点击课程卡片展开单词列表
- **进度追踪**：每个单词的学习状态（未学习/进行中/已掌握）

### 4. 练习系统重构（Practice Tab）
- **游戏卡片布局**：将现有练习游戏重新设计为卡片形式
  - 记忆配对游戏卡片
  - 闪卡练习卡片
  - 每个卡片显示游戏图标、标题、描述
- **游戏界面**：参考duolingo-clone的lesson界面设计
  - 顶部进度条
  - 中央内容区域
  - 底部操作按钮

### 5. 测验系统升级（Quiz Tab）
- **挑战界面**：采用duolingo-clone的challenge组件设计
  - 问题气泡样式
  - 选项按钮交互
  - 即时反馈动画
- **结果页面**：成功/失败的视觉反馈

### 6. 统计面板现代化（Stats Tab）
- **数据可视化**：使用图表组件展示学习进度
- **成就系统**：添加徽章和里程碑展示
- **学习历史**：时间线展示学习活动

### 7. 动画和交互增强
- **页面过渡**：smooth页面切换动画
- **按钮交互**：hover、click状态的微动画
- **进度反馈**：加载状态、成功失败动画
- **音效系统**：可选的学习反馈音效

### 8. 组件重构计划
1. **Layout组件**
   - 创建DuolingoLayout替换现有Container
   - 集成侧边栏和移动端导航
2. **Header组件**
   - 添加用户进度显示
   - 集成连击计数器和生命值
3. **Navigation组件**
   - 重构为侧边栏模式
   - 添加图标和活跃状态
4. **Tab组件重构**
   - LearnTab：课程树界面
   - PracticeTab：游戏卡片网格
   - QuizTab：挑战问答界面
   - StatsTab：数据统计面板

### 9. 状态管理增强
- **用户进度**：扩展useProgress hook
- **学习状态**：添加连击、经验值、等级
- **本地存储**：持久化用户学习数据

### 10. 性能优化
- **代码分割**：按页面和功能分割代码
- **图片优化**：优化icon和图片资源
- **缓存策略**：合理缓存用户数据

## Tests

### 1. 视觉回归测试
- **截图对比**：确保新UI与多邻国风格一致
- **响应式测试**：验证不同屏幕尺寸下的显示效果
- **主题测试**：验证颜色、字体、间距的正确应用

### 2. 功能测试
- **导航测试**：验证侧边栏和移动端导航的正确工作
- **学习路径测试**：验证课程解锁和进度追踪
- **游戏功能测试**：确保所有练习游戏正常工作
- **数据持久化测试**：验证用户进度正确保存和恢复

### 3. 交互测试
- **动画测试**：验证页面过渡和按钮动画流畅
- **触摸测试**：验证移动端触摸交互友好
- **性能测试**：确保动画不影响页面性能

### 4. 兼容性测试
- **浏览器兼容**：Chrome、Safari、Firefox、Edge
- **设备兼容**：桌面、平板、手机
- **操作系统兼容**：iOS、Android、Windows、macOS

### 5. 用户体验测试
- **可用性测试**：验证界面直观易用
- **可访问性测试**：确保符合无障碍标准
- **加载性能测试**：确保页面加载速度合理

### 免测说明
暂无免测项目，所有核心功能都需要完整测试验证。
