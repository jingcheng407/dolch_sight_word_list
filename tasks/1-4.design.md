# Design 1-4

## Requirements

**聚焦态左边界跳动修复**：
修复聚焦状态下的`padding`变化导致的左边界跳动问题。当前聚焦态会将`padding`从`3px`改为`20px 10px`（移动端`15px 8px`），造成左边界视觉跳动，必须保持`padding-left`一致性。

**具体要求**：
- 聚焦态保持`padding-left: 3px`与常态一致
- 只调整`padding-top/bottom/right`和`gap`来实现聚焦视觉效果
- 确保iPad布局兼容性
- 保持聚焦动画和交互体验不变

## Solution

**聚焦态左边界稳定方案**：

1. **问题分析**：
   ```css
   /* 当前实现 - 有问题 */
   .words-grid-bubbles {
     padding: 3px;  /* 常态 */
   }
   
   .bubble-words-container.bubble-focused .words-grid-bubbles {
     padding: 20px 10px;  /* 聚焦态：左边界从3px→20px，造成跳动 */
   }
   ```

2. **修改实施**：
   ```css
   /* 聚焦模式下的网格调整 - 保持左边界稳定 */
   .bubble-words-container.bubble-focused .words-grid-bubbles {
     padding-left: 3px;          /* 保持与常态一致，避免左边界跳动 */
     padding-right: 10px;        /* 保持原有右侧间距 */
     padding-top: 20px;          /* 保持原有顶部间距 */
     padding-bottom: 20px;       /* 保持原有底部间距 */
     gap: 15px;                  /* 保持原有间距 */
   }

   /* 移动设备上的聚焦效果优化 - 同样保持左边界稳定 */
   @media (max-width: 768px) {
     .bubble-words-container.bubble-focused .words-grid-bubbles {
       padding-left: 3px;        /* 保持与常态一致 */
       padding-right: 8px;       /* 保持原有右侧间距 */
       padding-top: 15px;        /* 保持原有顶部间距 */
       padding-bottom: 15px;     /* 保持原有底部间距 */
       gap: 12px;                /* 保持原有间距 */
     }
   }
   ```

3. **iPad兼容性考虑**：
   - iPad布局使用`var(--ipad-padding)`控制容器padding
   - 需要确保聚焦态修改与iPad padding值协调
   - 验证横竖屏切换时左锚点稳定

4. **代码注释**：
   ```css
   /* 关键修复：聚焦态保持左边界不跳动
    * 原因：用户期望左对齐布局，聚焦时左锚点应保持稳定
    * 方案：固定 padding-left 与常态一致，仅调整其他方向padding
    */
   ```

## Tests

**左边界稳定性测试**：

1. **聚焦态边界测试**：
   - 点击首行第一个气泡进入聚焦
   - 使用浏览器开发者工具测量首列气泡左边缘像素位置
   - 等待3秒自动退出聚焦
   - 再次测量首列气泡左边缘位置
   - 验证前后位置一致（允许1-2px次像素差异）

2. **不同气泡聚焦测试**：
   - 依次点击第一行、第二行、最后一行的气泡
   - 每次聚焦时观察首列气泡左边界是否稳定
   - 验证所有聚焦操作都不影响左锚点

3. **iPad兼容性测试**：
   - 如有iPad设备，切换横屏/竖屏模式
   - 验证`--ipad-padding`与聚焦态叠加后的左锚点稳定性
   - 确认响应式布局正常工作

4. **视觉回归对比**：
   - 截图修复后的聚焦/非聚焦状态
   - 与基准截图对比，确认左边界不再跳动
   - 验证用户视觉体验改善

5. **功能完整性验证**：
   - 确认聚焦动画效果正常（放大、虚化）
   - 验证聚焦状态的交互响应
   - 测试语音播放等功能未受影响
