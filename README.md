# 🌈 快乐学单词 - 儿童英语启蒙应用

一个专为5岁小朋友设计的可爱互动英语学习应用！通过有趣的卡通界面、动画效果和简单游戏，帮助孩子们轻松掌握Pre-primer级别的40个最基础英语常见词汇。

## ✨ 儿童友好特性

### 🎨 可爱的视觉设计
- **卡通风格界面**: 使用Fredoka One字体和可爱emoji装饰
- **彩虹色彩**: 明亮温暖的配色方案，吸引小朋友注意力
- **动画效果**: 丰富的CSS动画让学习更有趣
- **小动物吉祥物**: 小熊🐻、小兔🐰、小狮子🦁陪伴学习

### 🎯 学习模式 (和小熊一起学)
- **大字体显示**: 40个Pre-primer词汇卡片，字体大而清晰
- **点击发音**: 每个单词都有标准英语发音，自动播放
- **彩色分类标签**: 按词性用不同颜色区分（动词、形容词等）
- **星星进度**: 学过的单词会显示星星⭐奖励
- **简单操作**: 大按钮设计，易于小朋友点击

### 🎮 游戏模式 (和小兔一起玩)
- **翻卡片游戏**: 点击卡片翻面看例句，简单有趣
- **已删除复杂游戏**: 移除了记忆配对和拼写，专注简单互动

### 🧩 小测试 (小狮子考考你)
- **三个难度**: 😊简单(5题) 😃普通(8题) 🤗挑战(10题)
- **大按钮选择**: 选项按钮大而醒目
- **即时反馈**: 答对有彩色提示和鼓励
- **可爱结果页**: 用emoji和渐变色显示成绩

### 🏆 我的奖杯 (学习成就展示)
- **进度可视化**: 用图表和emoji显示学习统计
- **成就徽章**: 解锁不同阶段的学习成就
- **鼓励性语言**: 用简单易懂的话语鼓励孩子

## 技术栈

- **后端**: Python + FastAPI
- **前端**: HTML5 + CSS3 + JavaScript (原生)
- **语音**: Web Speech API
- **数据**: JSON格式词汇数据
- **依赖管理**: uv

## 安装和运行

### 前置要求
- Python 3.13+
- uv包管理器

### 安装依赖
```bash
uv sync
```

### 启动应用
```bash
uv run python main.py
```

应用将在 `http://localhost:8000` 启动

### 访问应用
在浏览器中打开 `http://localhost:8000` 即可开始使用

## API接口

### 获取所有单词
```
GET /api/words
```

### 获取随机单词
```
GET /api/words/random?count=10
```

### 获取单词详情
```
GET /api/words/{word}
```

### 获取测验题目
```
GET /api/quiz?count=5
```

### 获取学习统计
```
GET /api/stats
```

## Pre-primer词汇表

包含40个最基础的Dolch Sight Words：

**动词类**: can, come, find, go, help, jump, look, make, play, run, said, see, is

**形容词类**: big, blue, funny, little, red, yellow

**代词类**: I, it, me, my, we, you

**介词类**: for, in, to

**其他类**: a, and, away, down, here, not, one, the, three, two, up, where

## 使用说明

1. **学习模式**: 点击单词卡片查看详情和发音，支持按分类筛选
2. **练习模式**: 选择不同练习类型进行互动学习
3. **测验模式**: 完成选择题测验检验学习成果
4. **统计模式**: 查看学习进度和解锁成就
